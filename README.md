Dad Joke Showdown — the program writes one dad joke to `/output/entry.txt`: "What does a thesaurus eat for breakfast? Synonym rolls." A judge model compares dad jokes two at a time and picks the one that lands the bigger groan.

## Run it

```sh
node main.ts
```

Writes the single dad joke to `/output/entry.txt` (55 characters plus a trailing newline).
